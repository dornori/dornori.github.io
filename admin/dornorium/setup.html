🚀 Deploy Your Worker

Your worker isn't reachable yet. Follow these steps to deploy it to Cloudflare.

  1. 1 Go to dash.cloudflare.com and log in
  2. 2 Go to Workers & Pages → Create → Create Worker
  3. 3 Paste the Dornorium worker code into the editor
  4. 4 Go to D1 → Create database named dornorium-db
  5. 5 In Worker settings → Bindings → Add D1 binding: variable DB → select your database
  6. 6 Add Durable Object binding: class TicketHub → variable TICKET_HUB
  7. 7 Click Save and Deploy
  8. 8 Copy your worker URL (looks like https://your-worker.workers.dev)

🔐 Set Up Encryption Key

This key encrypts all sensitive data. Click the button below to copy it, then add it to Cloudflare.

This opens Cloudflare dashboard. Add a Secret named ENCRYPTION_KEY with the copied value, then Save and Deploy. Come back here and click "Verify" below.
