🏗️ Phase 1: Cloudflare Setup

Before Dornorium can run, you need a Cloudflare account with these services:

  • Cloudflare account created
  • D1 database created
  • Durable Object binding added
  • Worker deployed
  1. Go to dash.cloudflare.com and sign up/login
  2. Go to Workers & Pages → D1 → Create database
  3. Go to Workers & Pages → Create Worker
  4. In Worker settings, bind your D1 database as DB
  5. Bind a Durable Object named TICKET_HUB
  6. Add a secret named ENCRYPTION_KEY (any strong value)
  7. Add a secret named JWT_SECRET (any strong value)
  8. Deploy the worker, copy its URL (e.g. https://your-worker.workers.dev)

🔐 Phase 2: Encryption Key

This key encrypts all sensitive data. Add it to Cloudflare as a secret, then paste it below to verify.

  1. Copy the key above
  2. Cloudflare Dashboard → Workers → Your Worker → Variables
  3. Click + Add Secret → Name: ENCRYPTION_KEY
  4. Paste the key → Save and Deploy

⚠️ Save this key. Without it, encrypted data cannot be recovered.
