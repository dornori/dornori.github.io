Ultimate Beginner's Guide: Setting Up Your Gmail API Web App

Welcome! This guide will walk you through setting up a Google Apps Script that acts as a private API to send emails from your custom domain.

Step 1: Create a Google Apps Script Project

  1. Go to script.google.com and sign in with your Google account.
  2. Click the blue + New project button in the top-left corner.

Step 2: Paste Your Code and Save

  1. Paste the code block shown below into the editor (use the copy button right on the code block!):
  2. Then change the default credentials to your own liking - keep standard security recommendations in mind eg DO NOT! set "PASSWORD123" etc.
  3. SECRET_KEY: "YourSecretKey123", // Change this to your private security secret
  4. API_USERNAME: "user", // Change this to your desired API username
  5. API_PASSWORD: "SomePassword" // Change this to your desired API password
  6. Make sure you store these 3 credentials somewhere you will need these when setting up Dornorium
  7. Delete any text currently inside the Google App code editor.
/********************************************************************************
 * 🚀 USER CONFIGURATION SETTINGS (EDIT THESE VALUES BELOW)
 * ----------------------------------------------------------------------------
 * INSTRUCTIONS:
 * Change the text inside the quotes below to your own private credentials. 
 * You will need these exact values in the Dornorium setup to connect it to the Gmail App.

var CONFIG = {
  SECRET_KEY: "YourSecretKey123",  // Change this to your private security secret
  API_USERNAME: "user",             // Change this to your desired API username
  API_PASSWORD: "SomePassword"      // Change this to your desired API password
};


/********************************************************************************
 * CORE SCRIPT LOGIC (DO NOT EDIT BELOW THIS LINE)
 ********************************************************************************/
function doGet(e) {
  return handleRequest(e);
}

function doPost(e) {
  return handleRequest(e);
}

function handleRequest(e) {
  var p = e.parameter;

  // Validate the secret key
  if (p.secret !== CONFIG.SECRET_KEY) {
    return ContentService.createTextOutput(JSON.stringify({status: "error", message: "Unauthorized"}))
      .setMimeType(ContentService.MimeType.JSON);
  }

  // Validate username and password credentials
  if (p.username !== CONFIG.API_USERNAME || p.password !== CONFIG.API_PASSWORD) {
    return ContentService.createTextOutput(JSON.stringify({status: "error", message: "Invalid Credentials"}))
      .setMimeType(ContentService.MimeType.JSON);
  }

  try {
    var options = {
      htmlBody: p.message
    };
    if (p.from) {
      options.from = p.from;
    }

    GmailApp.sendEmail(p.to, p.subject, "", options);

    return ContentService.createTextOutput(JSON.stringify({status: "success"}))
      .setMimeType(ContentService.MimeType.JSON);
  } catch (err) {
    return ContentService.createTextOutput(JSON.stringify({status: "error", message: err.toString()}))
      .setMimeType(ContentService.MimeType.JSON);
  }
}
  1. Click the Save icon (floppy disk) at the top toolbar, or press Ctrl + S. Name your project something like "Gmail API Wrapper".

Step 3: Deploy as a Web App

  1. In the top-right corner, click the blue Deploy button, then select New deployment.
  2. Click the gear icon next to "Select type" and choose Web app.
  3. Fill out the fields:
    • Description: Dornorium GMail App
    • Execute as: Me (your email)
    • Who has access: Anyone (Critical step!)
  4. Click the blue Deploy button.

Step 4: Authorize Permissions

  1. Google will prompt you with an "Authorization required" window. Click Review permissions.
  2. Select your Google account.
  3. You will see a warning screen saying "Google hasn't verified this app". Click Advanced (small text on the bottom left).
  4. Click Go to Untitled project (unsafe).
  5. Click Allow at the bottom.
  6. Copy your generated Web App URL and save it somewhere safe. You will need this to configure Dornorium

Step 5: Setup Custom Domain "Send As" with an App Password

To send emails from a custom domain address (e.g., info@yourdomain.com) without security warnings, you must link it using Gmail's SMTP servers and a Google App Password.

Phase 1: Generate Your Google App Password

  1. Go to your Google Account Security Settings at myaccount.google.com/security.
  2. Make sure 2-Step Verification is turned on.
  3. Scroll down and click on App passwords.
  4. Select a name something like Dornorium SMPT, then click Create.
  5. Copy the generated 16-character password and keep it safe.
  • The below will require the email addresses you want to setup to have an inbox where mails can get routed to. This can be done from the Dornorium GUI so it's adviced you will skip the next step till you deployed Dornorium

    • Phase 2: Configure "Send As" in Gmail

    1. Open your regular Gmail inbox and click the Gear icon (Settings) -> See all settings.
    2. Go to the Accounts and Import tab.
    3. Under Send mail as:, click Add another email address.
    4. Enter your custom domain name (e.g., info@yourdomain.com) and click Next Step.
    5. Fill out the SMTP settings:
      • SMTP Server: smtp.gmail.com
      • Port: 465
      • Username: Your main Google account email address
      • Password: Your 16-character Google App Password (without spaces)
      • Select Secured connection using SSL
    6. Click Add Account a verification email is sent to the email address with a confirmation URL. Copy the URL from the email and load the google confirmation page. Press the Confirm button and the email address will now work once configured in the Dornorium user interface.
