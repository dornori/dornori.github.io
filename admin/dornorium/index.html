☁️ Step 1: Cloudflare Account

Create a Cloudflare account and generate an API token.

  • 1. Go to cloudflare.com/sign-up
  • 2. After signup, go to API Tokens
  • 3. Click + Create Token → Use template: Edit Cloudflare Workers
  • 4. Copy your Account ID and the generated API Token

💡 Save your credentials — you'll need your Account ID and API Token when running the installer.

These are required for the installation script to deploy Dornorium to Cloudflare Workers.

📧 Email Configuration (Optional)

To enable outgoing emails (password reset, notifications, etc.), create a Google Application for OAuth 2.0.

You can link your domain (e.g., example.com) to send emails under your own domain.

Read the INSTALLATION.md instructions for full configuration options.

⬇ Step 2: Download Installer

Download the installer for your operating system.

🪟 Windows .bat 🐧 Linux .sh 🍎 macOS .command

After downloading, run the installer. It will upload the configuration to your Cloudflare Workers.

📖 Read the instructions in the installer file for configuration options.

The installer will prompt you for your Account ID and API Token.

🚀 Step 3: Launch Dornorium

If the installer completed successfully and you downloaded and stored config.json in the root folder.

Click the button below to verify and enter the network.
