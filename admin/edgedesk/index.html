🔐 Step 1: Create Encryption Key

EdgeDesk encrypts all sensitive credentials at rest. Create a Cloudflare secret named ENCRYPTION_KEY using the key below.

  1. Cloudflare Dashboard → Workers → Your Worker → Variables
  2. Click + Add Secret
  3. Name: ENCRYPTION_KEY
  4. Value: paste the generated key below
  5. Click Save and Deploy

⚠️ Store this key securely. Without it, encrypted data cannot be recovered.

🗄️ Step 2: Initialize Database

Creates all required tables and seeds default configuration. Paste your encryption key to authorize.

👤 Step 3: Create Admin Account

Set up the first administrator. Use a strong, unique password.
