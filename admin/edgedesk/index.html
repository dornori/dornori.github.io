Step 1: Create Encryption Key

EdgeDesk encrypts sensitive credentials. You need to create a Cloudflare secret named ENCRYPTION_KEY.

  1. Open Cloudflare Dashboard → Workers → Your Worker → Variables
  2. Click Add Secret
  3. Name: ENCRYPTION_KEY
  4. Value: copy the key below
  5. Click Save and Deploy

⚠️ Save this key somewhere safe. You'll need it if you ever recreate the worker.

Step 2: Initialize Database

This will create all tables and seed default settings. Paste your encryption key to verify.

Step 3: Create Admin Account

This will be the first administrator account. Choose a strong password.
