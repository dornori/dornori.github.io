Connecting to EdgeDesk

🔐 Step 1: Create Encryption Key

Copy this key and add it as a Cloudflare secret. This secures all sensitive data.

  1. Open Cloudflare Dashboard → Workers → Your Worker → Variables
  2. Click + Add Secret
  3. Name: ENCRYPTION_KEY
  4. Value: paste the key below
  5. Click Save and Deploy

⚠️ Save this key somewhere safe. Without it, encrypted data cannot be recovered.

🗄️ Step 2: Initialize Database

Creates all tables and seeds default settings. Your encryption key is pre-loaded.

👤 Step 3: Create Admin Account

Set up the first administrator. Your encryption key is pre-loaded.
