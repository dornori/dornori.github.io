Add a Language

Select a language below and click Add Language. The admin will automatically:
• Translate all UI strings (site + shop) via API
• Translate all product names & descriptions
• Generate localised URL slugs (e.g. /sv/om-oss/, /it/chi-siamo/)
• Create the full URL folder tree on disk
• Scaffold content/<code>/ page stubs
• Update languages.json and slug-map.js

Add Custom Language
ℹ How it works
Content pages in content/<code>/ are scaffolded as stubs. Use the Pages view and click Translate All Langs on each page to fill them with translated content. URL slug folders (/test/<code>/) are created immediately and serve via the existing site-boot router. All changes are written to disk — nothing is temporary.
