DORNORI Manual v2.1

Complete guide for building and configuring your own DORNORI website. This manual is written for people who will create their own sites from scratch — starting with a basic template, then adding features as needed.

Minimal config.js Example

This is what a new user starts with — a small, manageable config:

const CONFIG = {
  // 1. Basic site info
  appearance: {
    base_path: '/',
    root_url: 'https://my-shop.com',
  },
  shopName: "My Shop",
  
  // 2. Start with just English
  defaultLanguage: "en",
  supportedLanguages: ["en"],  // add more languages later
  
  // 3. Simple navigation
  navigation: [
    { slug: 'shop', icon: 'shop-icon.svg', type: 'standard', enabled: true },
    { slug: 'about', icon: 'about-icon.svg', type: 'standard', enabled: true },
    { slug: 'contact', icon: 'contact-icon.svg', type: 'standard', enabled: true },
  ],
  
  // 4. Pages
  pages: {
    home: { file: 'home.html' },
    shop: { file: 'shop.html' },
    about: { file: 'about.html' },
    contact: { file: 'contact.html' },
  },
  
  // 5. Shop settings
  baseCurrency: "EUR",
  taxRate: 0.21,
  shipping: {
    freeThreshold: 100,
    base: 5,
    perKg: 1,
    estimatedDays: "3-5",
  },
  
  // 6. Payment (add your IDs later)
  payment: {
    activeProcessor: "paypal",
    paypal: {
      clientId: "",  // add this when ready
      currency: "EUR",
    },
  },
  
  // 7. Features
  features: {
    showLanguageSwitcher: false,  // only English for now
    showCurrencySelector: true,
    showGeoLanguagePopup: false,
    CartLive: true,
  },
};

How It Works

Architecture Overview

DORNORI is a Single Page Application (SPA) built with vanilla JavaScript. Here's how it loads and works:

Startup Sequence

1. index.html loads
   ↓
2. site-boot.js loads CONFIG + language files
   ↓
3. site-main.js sets up nav, theme, page router
   ↓
4. User clicks link → page-loader fetches HTML from content/[lang]/[slug].html
   ↓
5. Mounts components (slideshow, forms, shop) → displays page
   ↓
6. Browser URL updates (no page reload)

Key Principles

  • Configuration-Driven: Most features in js/config.js
  • No Dependencies: Pure JavaScript, no React/Vue/jQuery
  • Modular: Each feature can be disabled/enabled
  • Lazy-Loading: Shop, forms load only when needed
  • Content in Files: Pages, text, products are separate JSON/HTML files
First Steps

Quick Start — 10 Minutes

1. Copy the Starter Template

Take the example-starter/ folder and rename it to your project.

2. Edit js/config.js

Change these three values:

shopName: "Your Shop Name",
root_url: "https://your-domain.com",
payment.paypal.clientId: ""  // get from PayPal developer

3. Add Your Products

Edit data/products.json and add your products:

[
  {
    "id": "your-product",
    "name": "Product Name",
    "price": 49.99,
    "stock": 10,
    "image": "images/products/your-product.webp"
  }
]

4. Create Your Homepage

Edit content/en/home.html. Add product embeds:

<div data-shop-products="your-product"></div>

5. Open in Browser

Start a local server and navigate to http://localhost:8000. You now have a working shop!

ℹ️

Local development: Use Python: python3 -m http.server 8000 or Node: npx http-server

Settings

Configuration (config.js)

All site settings live in one place: js/config.js. Edit this file to customize everything.

Essential Settings You'll Change

SettingExamplePurpose
shopName"My Store"Your brand name
appearance.root_url"https://mystore.com"Your domain (for emails, canonical links)
baseCurrency"EUR"Your base currency for prices
taxRate0.21Tax percentage (0.21 = 21%)
shipping.freeThreshold100Free shipping over €100

Paths (usually don't change)

paths: {
  countries_file:  'data/countries.json',
  lang_dir:        'lang/',
  content_dir:     'content/',
  shop_dir:        'shop/',
  icons_dir:       'assets/icons/',
}

Storage Keys (for localStorage)

storageKeys: {
  lang:        'dornori-lang',
  theme:       'dornori-theme',
  cart:        'dornori-cart',
  currencyKey: 'webshop_currency',
}

These control where user preferences are saved. Change only if you have naming conflicts.

E-Commerce

Payment & Shipping Setup

PayPal Setup

  1. Go to PayPal Developer Dashboard
  2. Create an App
  3. Copy your Client ID
  4. Paste into config.js: payment.paypal.clientId: "YOUR_ID"

Stripe Setup

  1. Go to Stripe Dashboard
  2. Find Publishable Key in API Keys
  3. Paste into config.js: payment.stripe.publishableKey: "pk_live_..."
  4. Set up a backend endpoint for payment intents

Shipping Configuration

shipping: {

  base: 8.50,         // base cost
  perKg: 1.20,        // cost per kg
  maxFreeWeight: 20,  // max kg for free
  estimatedDays: "3–5",  // display text

Tax Configuration

Custom Events

Listen to shop events to react to changes:

EventWhenDetail
webshop:readyShop modules loaded—
shop:cartUpdatedItem added/removed/qty changed{ cart: [...] }

Example: Update Cart Count

  const count = e.detail.cart.reduce((a, i) => a + i.qty, 0);

Common Issues

Page Not Loading

Problem: Blank page or 404 error
  • Check F12 Console for errors
  • Verify file exists: content/en/[slug].html
  • Verify page registered in config.js → pages object
  • Check base_path matches your server setup

Shop Not Showing

Problem: Products don't appear
  • Check F12 Network tab — is data/products.json loading?
  • Verify JSON syntax (use JSONLint)
  • Ensure images exist: images/products/[id].webp
  • Check webshop:ready event fires in console

Payment Not Working

Problem: PayPal/Stripe button missing
  • Verify config.js has correct Client ID or Publishable Key
  • Check F12 Console for API load errors
  • For PayPal: clientId must not be empty
  • For Stripe: key must start with pk_

Products Have Wrong Images

Problem: Wrong images showing
  • Check image paths in products.json match actual files
  • Ensure both .webp and .jpg exist
  • Use lowercase, hyphens only (e.g., product-001.webp)
💡

Debug tip: Open F12 Console (press F12). Most issues are obvious errors there. If you see "JSON parse error", check your JSON files with JSONLint.
